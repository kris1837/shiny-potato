# Rooted seed shop

An interactive first release for a climate-aware seed shop for personal gardens.

## Included

- Country, climate profile, soil, and garden-bed inputs
- Suitability-filtered seed catalogue for tomato, cucumber, peas, corn, radish, and beans
- Bed-size seed recommendations with a germination allowance
- Individual-seed pricing and automatic 25+ / 100+ quantity discounts
- Persistent browser cart and order-request placeholder (payments intentionally excluded)
- Responsive, dependency-free interface

## Run locally

Open `index.html` in a browser, or serve the directory with any static-file server. No build step or package installation is required.

## Next implementation stage

Connect the client-side catalogue to a database and admin workspace, validate climate-profile data by region, and replace the order-request placeholder with delivery and payment workflows.
